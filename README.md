# Sadə İstifadəçi Login Sistemi

Bu layihə Python dilində yazılmış sadə bir login (daxil olma) sistemidir.  
Proqram istifadəçinin daxil etdiyi parolu yoxlayır və düzgün olduqda istifadəçini qarşılayır.

---

## Texnologiyalar
- Python 3.x
- OOP (Classes və Methods)

---

## Layihənin Təsviri
- `User` sinfi:
  - `username` → istifadəçi adı
  - `password` → istifadəçi parolu
- `found_loggin(password)` metodu:
  - Əgər daxil edilən parol düzgündürsə → `"successfull!,Welcome"` qaytarır
  - Əks halda → `"error"` qaytarır
